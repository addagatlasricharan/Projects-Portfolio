## 3. Automated Cloth Cutting Machine

An engineering project combining **software, electronics, and mechanical systems** to automate cloth cutting.

The project uses a microcontroller-based control system to operate a stepper motor and provide user-controlled cutting and sheet-feeding functionality.

### 🛠️ Technologies & Components

- Arduino
- C/C++
- Stepper Motor
- Stepper Motor Driver
- Keypad
- I2C LCD
- IR Sensor
- Embedded Control Logic

### ✨ Key Features

- Automated cloth cutting
- Adjustable bag/cloth length
- Stepper motor control
- Keypad-based user input
- LCD-based interface
- Sheet counting
- Manual sheet feeding
- Forward and backward feed control
- IR-based blade position detection
- Multiple operating speeds

### 🎯 Project Focus

This project combines:

**Software + Electronics + Mechanical Systems**

with the goal of developing a practical automated manufacturing solution.
